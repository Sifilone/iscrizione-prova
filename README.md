# Iscrizioni Prova

Bozza statica del sito Iscrizioni Prova. Apri `index.html` in un browser per visualizzarla.

Per pubblicarla su GitHub Pages:
1. Crea un repository pubblico chiamato `iscrizioni-prova`.
2. Carica `index.html` nella radice.
3. Vai in Settings → Pages.
4. Seleziona Deploy from a branch, branch `main`, folder `/ (root)`, salva.

Il modulo attualmente è dimostrativo e non raccoglie dati.
